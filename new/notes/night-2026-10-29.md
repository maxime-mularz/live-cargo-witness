## What was built and fixed (commits `346f42c`…`1ae9cb9`, all pushed)

- `recording_list.py` covers the demo dossiers and prints full paths (DEMO-02's filmed answer was
  missing).
- **Lot B — drafts** (`new/lcw/drafts.py`): `draft_notification(recipient)` builds a fixed English
  template from verifier-accepted claims only; the model's free `summary` argument was dropped
  (masking removes forbidden words, not invented numbers); recipients are `shipper`, `carrier`,
  `ground_handler`; drafts are written to `drafts/<recipient>.md`, covered by the manifest, and
  start with "DRAFT — NOT SENT. A human reviews, signs and sends."
- **Lot C — French PV**: `pv.fr.md` in every case, from `pv.json` alone (French labels, `title_fr`,
  French signature lines), verified statements and quotes kept in English and quoted, "the English
  version prevails", SYNTHETIC banner, in the manifest. French forbidden stems added to `vocab.py`.
- **Fixes from the reviews**:
  - an empty reading written as `""` or `[]` escaped the retry, and an unread air waybill could
    give a false R01 "violated" (empty handling codes);
  - prompt: a document-comparing rule (R03) is unreadable as soon as one document is unread;
    `dossier_field awb_number_declared` also grounds an AWB number;
  - **times**: an interval sent with an offset (`18:15+05:00`) passed the verifier and was printed
    "18:15 UTC" in pv.md, the drafts and the journal (it is 13:15 UTC). Submitted start/end values
    are now rewritten in UTC before the verifier (fractions kept, unparseable values left for the
    verifier to reject), a rejection explains the rewrite when it is about a date or time, and
    `get_sensor_curve` / `ask_handler` bounds are logged in UTC. Took 4 review rounds.
  - French PV: a basis line that cannot be rebuilt in French is kept in English, never dropped;
    the stem `véto` now needs the accent (it caught the English "veto").
  - **verifier**: malformed claims (evidence not a list of objects, rule id not a string, curve
    segment with a null or overflowing start) crashed the batch; they are now rejected with a
    reason, and any remaining exception rejects that claim, never accepts it. CA-06 still 5/5.
  - prompt: removed the number words the prompt itself used ("the three documents"), which the
    model copied into statements; a test keeps them out.
- Docs: CLAUDE.md and README say which model parts ran live (no score in the README); the
  Baseten model id was set to the one Baseten serves (`meta-models/muse-spark-open`).
